
 RTXUI CSS Grid Layout Demo

 This demo showcases the CSS Grid layout support in RTXUI. The container uses
 display: grid, the new shorthand grid-template: 1fr 1fr 1fr 1fr / 1fr 2fr 1fr,
 and gaps. Spanning is also demonstrated (item 1 spans 2 columns, item 5 spans
 2 rows).
