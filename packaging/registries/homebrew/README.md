# ArthurSonzogni's Homebrew tap

```sh
brew install arthursonzogni/tap/rtxui
```

| Formula | Project |
| :--- | :--- |
| `rtxui` | [RTXUI](https://github.com/ArthurSonzogni/RTXUI): C++ terminal user interfaces built from HTML templates, CSS and reactive state |

The formulae are written by each project's release automation
(RTXUI: `scripts/publish_registry.py homebrew`). Edit them there, not here.
