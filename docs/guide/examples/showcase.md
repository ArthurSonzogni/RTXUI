# A gallery of interface patterns a terminal application needs

A gallery of interface patterns a terminal application needs.

A command palette, notifications, a table with a details drawer, a form with validation, a task runner and a confirmation dialog. Every motion has a job: it shows where something came from, what changed, or how long is left. Nothing moves only to move.

Try it: press Ctrl+K anywhere and type. Sort and filter the table, then press Enter on a row. Submit the form empty. Run the tasks.
