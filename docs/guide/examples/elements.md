# Every built-in element, one page each

Every built-in element, one page each.

Each page is a small component. Beside it is that component's template, shown as it is: what you read on the right is what draws on the left. The look of the controls comes from one theme, kTheme, as an application would have.

Try it: pick an element on the left, or press Page Down and Page Up. Use each one, with the mouse or with Tab and the arrows.
